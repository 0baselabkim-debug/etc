키움 PC 수급 수집기 — Windows 10/11, Python 3.12 이상

현재 상태: 프로그램 구현·자동 테스트 완료. 사용자 PC의 실제 API 수집은 아직 미검증입니다.
키움 REST API만 호출합니다. 매매 주문·계좌 잔고 조회 기능은 없습니다.

처음 한 번
1. ZIP을 다운로드한 뒤 마우스 오른쪽 버튼 > 모두 압축 풀기.
   압축파일 안에서 직접 실행하지 마세요. 예: 문서\KIWOOM_PC.
   설치 폴더 전체를 OneDrive 등 공유·동기화 폴더에 두지 마세요. .env가 포함됩니다.
2. 키움 REST 홈페이지 https://openapi.kiwoom.com 에 로그인합니다.
   API 사용신청 > IP 등록에서 '현재 나의 IP'를 확인·등록합니다.
   이미 이 PC 네트워크 IP를 등록했다면 생략합니다. 기존 키를 그대로 사용합니다.
3. 01_설치.cmd를 더블클릭합니다. 기존 .env 파일을 선택하면 복사됩니다.
   KIWOOM_APP_KEY와 KIWOOM_APP_SECRET이 들어 있는 기존 파일을 사용하세요.
   Python이 없으면 공식 다운로드 페이지가 열립니다. Windows installer (64-bit)를
   설치한 뒤 01_설치.cmd를 다시 실행하세요. 설치 옵션의 Tcl/Tk는 기본값대로 유지합니다.
4. 02_수집실행.cmd를 더블클릭합니다. 날짜 확인 창에서 확인을 누릅니다.
   처음에는 최근 장이 열린 날을 선택하세요. 오늘 날짜는 한국시간 20:30 이후 가능합니다.
   KOSPI·KOSDAQ 목록 전체를 조회하므로 수천 종목 기준 1시간 안팎 또는 그 이상 걸릴 수 있습니다.
   다른 프로그램에서 같은 키움 계좌로 대량 조회하지 마세요. 초당 5회 한도를 함께 사용합니다.
5. 완료되면 '보낼파일' 폴더의 kiwoom_날짜.zip 한 개를 이 Codex 대화에 첨부해 주세요.
   인증 실패·부분 성공도 이 ZIP에 기록됩니다. .env나 설치 폴더 전체는 보내지 마세요.
   PC 수집 결과를 확인한 뒤에만 스크리너 2단계 개발을 진행합니다.

자동 수집 (첫 수집 결과 확인 후 권장)
- 03_자동수집등록.cmd를 더블클릭하면 매일 한국시간 20:30 예약이 등록됩니다.
- Windows 시간대는 서울이어야 합니다. PC 전원과 인터넷이 켜져 있고 로그인된 상태가 필요합니다.
- 주말은 건너뜁니다. 공휴일·시장 임시 휴장은 공식 거래일 달력이 없어 자동 확정하지 않습니다.
  요청일 데이터가 없으면 누락으로 표시하며 0원으로 채우거나 성공 처리하지 않습니다.
- 늦게 켜면 작업 스케줄러가 실행 가능한 시점에 시작합니다. 여러 날 누락됐다면
  02_수집실행.cmd에서 각 날짜를 선택하여 실행하세요. 과거 날짜의 목록은 현재 상장목록을
  기준으로 하므로 과거 상장폐지 종목까지 포함하는 역사적 전수 수집을 보장하지 않습니다.
- output\schedule.log에서 최근 자동 실행 상태를 확인할 수 있습니다.
- 해제하려면 05_자동수집해제.cmd를 실행합니다. 폴더를 옮기기 전 예약 해제 후 새 위치에서 다시 등록하세요.

중단·재개와 누락
- 창이 종료되거나 인터넷이 끊겨도 성공한 종목은 PC에 저장됩니다.
- 같은 날짜로 다시 실행하면 검증을 통과한 저장분은 건너뛰고 미완료·오류 종목을 재조회합니다.
- 날짜별 종목 목록은 첫 조회 시 고정합니다. 동일 날짜 중복 행을 추가하지 않습니다.
- 통신 장애·서버 5xx·조회 제한에는 최대 3회 시도하며 대기 시간을 늘립니다.
- IP·인증 오류는 즉시 중단합니다. 토큰 발급은 실행당 1회이며 자동 재시도하지 않습니다.
- 8050은 API 사용신청의 IP 등록 확인, 8010은 실행 중 IP 변경 여부를 확인합니다.
  토큰 발급과 데이터 조회를 동일 PC·네트워크에서 수행하세요. 토큰은 파일에 저장하지 않습니다.
- 동일 PC에서 폴더 하나로 사용하세요. 여러 복사본을 동시에 실행하지 마세요.
- complete는 키움이 반환한 두 시장 목록의 해당 날짜 수집 완료입니다.
  보통주 모집단의 독립 대조, 정규장만의 집계 여부, 확정 수급 여부는 별도 검증이 필요합니다.
- 20:30은 운영상 수집 시각이며 키움의 최종 확정 보장 시각으로 확인된 값은 아닙니다.
  이미 성공한 종목은 이후 자동 갱신하지 않습니다. 공급자 정정분 반영은 향후 검증 대상입니다.

결과 파일
- output\YYYYMMDD\flows.csv: 종목별 외국인·기관 순매수 금액. UTF-8 CSV.
  원 단위 foreign_net_krw / institution_net_krw, 원래 백만원 값도 함께 보존합니다.
  0은 실제 API가 0으로 반환한 경우만 기록합니다. 빈 값은 오류 처리합니다.
- universe.csv: 해당 날짜에 사용한 KOSPI·KOSDAQ 목록. 우선주 등 임의 제외 없음.
- missing.csv: 누락·실패·미시도 종목과 이유.
- report.json: 대상·성공·실패 건수, 날짜, 시장, 단위, 인증 실패 분류와 호출 기록.
- manifest.json: 파일별 SHA-256 검증값.
- kiwoom_YYYYMMDD.zip: 위 다섯 파일만 포함한 전달용 묶음. 키·토큰·.env 제외.
  해시는 전송 중 손상 검사용이며 발신자 전자서명을 대신하지 않습니다.
- Excel에서 CSV를 직접 열면 005930의 앞 0이 사라질 수 있습니다.
  원본 CSV는 유지하세요. 프로그램과 DuckDB에서는 종목코드를 문자열로 읽습니다.

간편 전달
- 기본: '보낼파일'의 ZIP만 이 대화에 첨부합니다. GitHub 계정이나 업로드 키가 필요 없습니다.
- 선택: 04_전달폴더설정.cmd에서 별도의 비공개 OneDrive 폴더, 외장 드라이브 또는
  이미 연결한 개인 NAS 폴더를 선택하면 이후 ZIP만 그곳에 자동 복사합니다.
  동기화 서비스가 설치되어 있다면 그 서비스가 전송을 담당합니다.
  이 설정만으로 Codex가 자동 다운로드하는 것은 아닙니다. 접근 연결은 별도입니다.
- 외부 웹서버 개방·공개 링크 생성·GitHub 데이터 업로드는 하지 않습니다.

개발 검증과 한계
- Linux에서 모의 HTTP 응답을 이용해 재시도·연속조회·단위·날짜·중복·재개·ZIP 검증을 테스트했습니다.
- Windows에서의 실제 더블클릭 설치·작업 스케줄러 실행 및 키움 실제 수급 수집은 사용자 PC에서 확인해야 합니다.
- 클라우드의 성공한 KRX·DART·FRED·ECOS 연결은 변경하지 않았습니다.
- 최종 수급 기본 공급원 지정과 스크리너 DB 적재·분석 개발은 PC 결과 검증 전까지 보류합니다.
