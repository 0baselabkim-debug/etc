추가 설치 없는 키움 수집기

1. 시작.cmd를 더블클릭하세요.
2. 처음 한 번, 화면에서 기존 .env 파일을 선택하세요.
3. '수집 시작'을 누르세요.

Python 설치·패키지 설치·명령어 입력·코드 수정은 필요 없습니다.
Windows 10/11에 기본 포함된 PowerShell과 .NET으로 실행합니다.
시작 파일은 필요한 프로그램을 내 계정의 LocalAppData\KiwoomEasy에 준비합니다.
설정 파일과 데이터도 그 개인 폴더에 보관합니다. 관리자 권한은 필요 없습니다.

처음 키움 IP 등록이 필요하면 화면의 '키움 IP 등록' 버튼을 누르세요.
키움 홈페이지 로그인 → API 사용신청 → 현재 나의 IP 등록 순서입니다.
이미 이 PC의 공인 IP를 등록했다면 생략하세요. 기존 API 키를 사용합니다.
키움의 본인 로그인과 허용 IP 등록은 사용자가 직접 해야 합니다.

완료되면 결과 폴더가 자동으로 열립니다.
kiwoom_날짜.zip 파일만 이 대화에 첨부해 주세요. 실패한 경우에도 결과를 보낼 수 있습니다.
.env 파일이나 프로그램 보관 폴더 전체는 공유하지 마세요.

전체 종목은 1시간 이상 걸릴 수 있습니다. 수집 중에는 PC 전원을 켜 두세요.
같은 날짜로 다시 실행하면 정상 저장분은 재사용하고 미완료 종목부터 재개합니다.
수급이 없는 날짜·종목은 누락으로 기록합니다. 0원으로 채우지 않습니다.
KRX 종목코드로 외국인·기관 금액을 조회하며 백만원 원본과 원화 환산값을 함께 저장합니다.

자동 실행이 필요하면 화면의 '자동 수집 켜기'를 누르세요.
서울 시간대 기준 매일 오후 8시 30분, PC가 켜져 있고 로그인된 상태에서 실행됩니다.
주말은 건너뜁니다. 공휴일은 실제 데이터 부재를 누락으로 표시합니다.
여러 날 PC를 껐다면 화면에서 빠진 날짜를 선택해 수집하세요.
자동 실행을 중단하려면 '자동 수집 끄기'를 누르세요.
이전 Python 버전의 예약을 이미 등록했다면 그 버전의 '05_자동수집해제.cmd'로 해제하세요.

'결과 ZIP을 복사할 폴더 선택'은 선택 사항입니다.
이미 사용하는 비공개 OneDrive·NAS 폴더를 지정하면 결과 ZIP만 복사합니다.
이 설정만으로 Codex 자동 수신이 연결되는 것은 아닙니다. 기본은 ZIP을 대화에 첨부하는 방식입니다.

공식 조회 제한은 국내주식 계좌·토큰별 초당 5회이며 이 프로그램은 초당 1회로 제한합니다.
다른 프로그램에서 같은 계좌로 대량 조회하지 마세요.
조회 제한·통신 장애는 대기 후 최대 3회 시도합니다. 인증·IP 오류는 즉시 멈춥니다.
토큰은 메모리에만 유지하고 파일이나 결과 ZIP에 저장하지 않습니다.

검증 상태
- 수집·재시도·중복 방지·재개·CSV·결과 ZIP을 모의 응답으로 실행 테스트했습니다.
- 기존 Python 검증기로 이 프로그램의 ZIP을 검사해 호환성을 확인했습니다.
- 실제 Windows 화면/예약 실행과 사용자 PC의 키움 실데이터 수집은 아직 확인 전입니다.
- 보통주만의 독립 대조, 수급의 정규장 전용 여부·최종 확정 시각은 별도 검증이 필요합니다.
- 과거 날짜의 목록도 현재 상장목록 기준입니다. 역사적 전수 목록을 보장하지 않습니다.
- 성공한 종목의 사후 정정 수치는 자동으로 덮어쓰지 않습니다.
- 실제 PC 수집 성공을 확인한 다음에 스크리너 2단계를 진행합니다.
