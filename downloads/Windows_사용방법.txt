KIS PC 검증 도구 — Windows 사용법

1. ZIP 파일을 마우스 오른쪽 버튼으로 눌러 '압축 풀기'를 선택하세요.
   ZIP 안에서 실행하지 말고, 압축을 푼 폴더를 여세요.

2. 기존 .env 파일을 run_windows.cmd가 있는 폴더에 복사하세요.
   파일 내용을 수정하거나 인증키를 채팅에 보낼 필요는 없습니다.
   .env 파일이 .env.txt로 저장됐으면 실행 도구가 .env로 복사합니다.

3. run_windows.cmd를 더블클릭하세요.
   처음에는 필요한 패키지를 설치하므로 인터넷 연결이 필요합니다.
   Python 3.12 이상이 없으면 설치 안내가 나옵니다.
   공식 설치 페이지: https://www.python.org/downloads/windows/
   설치 화면에 Python Launcher 설치 항목이 있으면 선택하세요.

4. 실행이 끝나면 output 폴더의 kis_probe_result.zip만 이 채팅에 첨부하세요.
   접속 실패 시에도 진단 결과를 공유하면 원인을 확인할 수 있습니다.
   .env, .kis_local, .venv 폴더는 첨부하지 마세요.

주의 사항
- 관리자 권한은 필요하지 않습니다.
- 보안 프로그램 경고를 무조건 무시하지 마세요. 조직 PC는 보안 정책을 따르세요.
- API 키와 토큰은 GitHub ZIP에 포함하지 않았습니다.
- 실제 수급 조회 대상은 대표 종목 2개이며 전 종목 수집이나 주문을 하지 않습니다.
- 실패 직후 다시 실행할 때는 토큰 발급 제한 때문에 1분 기다리세요.
- 금액 단위와 전체 종목 커버리지는 아직 검증되지 않았습니다.
- Windows에서의 실제 실행 및 KIS 접속은 사용자 PC에서 확인해야 합니다.
